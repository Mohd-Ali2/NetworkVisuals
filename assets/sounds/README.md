# Packet sound assets

Place the two CC0 WAV files in this directory using these exact filenames:

- `packet-send.wav` — [Download Send Swoosh (CC0)](https://mildlyuseless.com/res/sfx/ui/ui-send-swoosh.wav)
- `packet-arrival.wav` — [Download Notification Pop (CC0)](https://mildlyuseless.com/res/sfx/ui/ui-notification-pop.wav)

Both effects are from Mildly Useless and are released under CC0 1.0 (public domain dedication). The source pages and license are listed below:

- https://mildlyuseless.com/res/ui-send-swoosh
- https://mildlyuseless.com/res/ui-notification-pop
- https://mildlyuseless.com/res/license

The app loads these files locally; no third-party audio hosting is required.
